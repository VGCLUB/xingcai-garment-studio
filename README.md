# 形裁 · 服装制版与棚拍工作台

解压整个文件夹，在桌面 Chrome 或 Edge 中打开 `index.html`。工作台使用本地 JavaScript 和 WebGL 计算布料、显示面料、生成棚拍图。它可以断网运行。六件试做服装可以从「新建工程」下的「打开试做样衣」直接打开。

## 收褶纱裙

从「新建工程」选择「潮汐 · 收褶纱裙」。前后腰头分别将 60 cm 的外纱收进 40 cm 的腰缝。在「缝线检查」中可标记抽褶缝，长边位于裁片顶边时，褶量在腰缝以下 8 cm 内逐步展开。「面料与布置」支持按裁片选择 1.4–4 cm 的网格间距。样衣以经纬纱交错值驱动粗糙度。收褶样衣目录含工程、纸样、GLB 和棚拍。运行 verify-gathers.cjs 可重做试穿和导出。

## 先看衣服

打开「燕麦色压褶裙」后拖动人台观察裙褶；打开「浅弧领长背心」观察领口包边和提花。点 3D 视窗右上角「棚拍渲染」，选灯光、机位、分辨率与采样数，然后点「导出成衣 PNG」。正面、背面、四分之三和面料近景各有独立的构图。「当前视角」沿用手动旋转和缩放后的相机。

样衣文件夹包含可编辑工程、等比例纸样 SVG、当前布网 OBJ、带纹理的 GLB、操作截图与独立棚拍 PNG。四张棚拍图均为 2048 × 2560，短衫还有一张背面图和一张 3072 × 3840 的面料近景。拼图来自工作台的实际输出。

## 制作与试穿

| 操作 | 用法 |
| --- | --- |
| 从零画纸样 | 新建空白工程，选「画新片」，依次点轮廓角点后点「完成轮廓」。画布标尺长 10 cm。 |
| 改版与曲线 | 拖角点，或点边后编辑起点坐标与弧高。整片长宽可数值调整，也可在边上加点、删点、复制或镜像复制裁片。 |
| 分片 | 选「分割」，点同一片上两个不相邻角点。新片保留原布置，外缘缝线会转移，切开的两边会自动配缝。 |
| 缝合与检查 | 点「缝合」，依次点两条边。下方列出两边长度与差值，超过 1 cm 会着色。可翻转方向、拆除、撤销和重做。 |
| 布置与面料 | 展开「面料与布置」，可以换前侧、后侧或平面布置，改高度、偏移、旋转和顶边固定方式。改颜色、织纹、绒光、粗糙度或纹理倍率时，当前试衣形状会保留。更换布种会重新计算物理约束。 |
| 人台与垂坠 | 可调胸、腰、臀围，显示人台和碰撞轮廓共用相同截面。模拟可暂停、继续或重新布置。收拢比例改变初始布置；压褶深度与褶距控制近似定型约束。深度为零时走普通垂坠。 |
| 保存与恢复 | 「保存」导出纸样、面料、人台、缝线、灯光及当前试衣帧。再次打开可恢复相同网格位置并继续模拟。浏览器暂存最近一次编辑的设计，显式保存可留住精确帧。支持导入第一版双片裙工程。 |
| 出纸样 | SVG 以厘米定义物理尺寸，含曲线缝合线、统一外扩缝份、配缝编号及方向标记、10 cm 校验尺。打印时使用 100% 并核对校验尺。 |
| 出模型 | OBJ 保留当前模拟网格和纸样 UV，坐标为米；GLB 包含细分衣片、立体包边和内嵌面料纹理，能独立交给其他三维工具。 |

`skirt.html` 保留第一版的双片裙参数化编辑入口。

## Blender 材质模块移植

选中裁片后点右侧「材质节点」。Principled BSDF 面板包含 IOR、粗糙漫反射、绒光、各向异性、涂层、透射、厚度、吸收距离与颜色、RGB 散射半径和自发光参数。欧根纱与柔光绒布预设分别适合薄透纱层与漫散射衬布。材质修改直接更新当前试衣帧。面料预设调整着色参数，布料物性由「面料与布置」中的布种控制。

点「编辑节点图」可把旧材质升级为可增删、重连的材质图。可添加图像、映射、噪声、波纹、沃罗诺伊、数学、范围映射、颜色渐变、混合颜色、法线、凹凸、Principled、透明、自发光和混合着色器等节点。在节点的输入端口选择来源，连线会覆盖对应输入的默认值。图像支持 PNG、JPEG、WebP，单图上限 8 MB、边长上限 8192 像素。颜色图使用 sRGB，法线图和粗糙度图使用线性数据。

「导出材质」保存 `.xcmat.json`，「保存」将材质图及自定义贴图嵌入工程。每个裁片有独立材质，「应用到全部裁片」可统一材质参数。`材质验证/` 中有四组可直接打开的工程、独立材质、GLB、实际棚拍和同机位对照。四组对照使用同一件压褶裙、染色、试衣帧、灯光、机位和采样数。

本次采用 Blender **4.5.0 Cycles** 的 Apache-2.0 源码，将多重散射 Sheen 绒光、3072 项 LTC 查找表、改进 Oren–Nayar 粗糙漫反射及其能量补偿移入 `cycles-material.js`。源码快照、修改说明和完整许可证位于 `vendor/cycles/`。`material-system.js` 将支持的材质图连接到形裁的 WebGL 后端。[上游绒光源码](https://github.com/blender/blender/blob/v4.5.0/intern/cycles/kernel/closure/bsdf_sheen.h) · [上游漫反射源码](https://github.com/blender/blender/blob/v4.5.0/intern/cycles/kernel/closure/bsdf_oren_nayar.h)

透射使用屏幕空间折射、Fresnel 和 Beer–Lambert 衰减，贴图或程序纹理可以驱动透射权重。次表面散射移植 Cycles 的 Christensen–Burley 半径拟合与累积分布式，用局部曲率及薄片厚度估算散射和背光。透射阴影按节点的覆盖率采样。GGX、各向异性和涂层继续由 Three.js 计算。[上游 BSSRDF 源码](https://github.com/blender/blender/blob/v4.5.0/intern/cycles/kernel/closure/bssrdf.h)

「潮汐 · 欧根纱叠裙」使用两片纱和两片内衬，纱线纹理驱动凹凸与透射。新建工程菜单可直接打开完成 120 步模拟的试衣帧。布料层级针对围绕人台的裙装，按内层的径向轮廓约束外层。采用 2620 个外层三角形面心作径向检测，本样衣穿入内衬超过 0.05 cm 的样点由 92 降为 0。棚拍图、近景、同机位对照和源工程在 `透射样衣/`。

当前覆盖形裁节点库内的表面材质。着色器混合按参数插值，折射使用屏幕空间缓冲，散射使用薄片近似。完整 Blender 节点库、节点组、体积、几何位移、随机游走散射及 `.blend` 直接导入仍待接入。GLB 导出薄片透射及主材质的标准参数，工程材质图写入 extras。程序运算、次表面散射和多层折射在通用查看器中会有差异。

## 渲染如何实现

- **面料。** 棉针织、亚麻、四叶纹提花使用摄影布样的颜色、切线法线和粗糙度贴图。颜色经过中性化处理，再按裁片染色；纹理按纸样厘米坐标铺设，随布料一起弯曲。另有程序薄绸材质。默认纹理倍率按原布样约 26–28 cm 的实物重复尺寸设置。摄影和处理分别由 Poly Haven 标注的 colormass 与 Rico Cilliers 完成，贴图按 CC0 发布。[棉针织](https://polyhaven.com/a/cotton_jersey) · [亚麻](https://polyhaven.com/a/rough_linen) · [提花](https://polyhaven.com/a/quatrefoil_jacquard_fabric) · [素材许可](https://polyhaven.com/license)
- **光照与采样。** 参考 EEVEE 的低差异采样与抖动阴影设计，`film.js` 独立实现相机亚像素偏移、主光位置采样、半精度线性颜色累积和深度接触遮蔽。最后一次做色调映射和输出转换。可选 1、8、16 次采样。1 次为快速直接输出；精细模式需要能够渲染到浮点纹理的显卡。此管线在形裁内执行，运行依赖是浏览器的 WebGL。[EEVEE 采样实现](https://github.com/blender/blender/blob/v4.5.0/source/blender/draw/engines/eevee/eevee_sampling.cc) · [EEVEE 阴影设置](https://docs.blender.org/manual/en/4.5/render/eevee/light_settings.html)
- **衣片表面。** 编辑时使用物理网格。导出棚拍与 GLB 时对衣片和包边做两级曲面细分。未缝边的折边沿实际裁片边界生成，用三角形重心坐标跟随布片变形。`finishes.js` 管理包边和细分，`textiles.js` 管理材质，`viewer.js` 管理灯光、相机与模型输出。
- **同机位对照。** `同机位棉布对照.png` 使用同一份短衫试衣帧、相机、灯光和采样数。左图使用程序棉布材质，右图使用摄影棉针织材质。下排是两次输出相同像素位置的原尺寸裁切。

## 实际试做与验证

| 样衣 | 实际操作 | 核验 |
| --- | --- | --- |
| 双色拼片裙 | 在裙身腰口和下摆加点，分割前后片，给四片分别配色与格纹 | 四片四条缝线，分片后原侧缝保留，SVG 含 1.2 cm 缝份 |
| 浅弧领长背心 | 调领口弧高、前后片长度、胸围，重缝肩线，换提花 | 单改前片会提示缝长差。保存后重开，模拟顶点逐个恢复 |
| 连袖短衫 | 从空白画布逐点画前身、复制后身、分别修领口、手工建立八条缝线 | 已导出正侧角度、背面和面料近景，检查过领口、袖口和织纹 |
| 燕麦色压褶裙 | 扩宽腰口和裙摆，设置 64% 收拢、3.1 cm 压褶深度、14 cm 褶距 | 用 16 次采样导出，实际几何与光影一起表现裙褶 |

物理复测检查了固定点、数值有效性、人台围度和肩部穿透。默认背心在第 24、60、120 步检查三角形面心，最大允许穿入 0.1 cm；第 120 步肩线对应节点最大间距约 0.004 cm。浏览器操作测试覆盖从空白制版到导出、旧版工程、损坏输入、撤销重做、刷新恢复和窄屏布局。四件样衣的 GLB 均通过 Khronos glTF Validator，错误数和警告数均为 0。

在目录内执行 `node verify-garment.cjs` 可重做当前求解器检查，`node verify-cloth.cjs` 可测试第一版裙装。浏览器回归脚本 `verify-studio.cjs` 需要本机 Chrome 和 Playwright Core，可通过 `CHROME_PATH`、`PLAYWRIGHT_CORE` 指定位置。可选的目录参数用于保存测试过程中实际导出的文件。

`verify-material.cjs` 独立读取上游查找表，检查实际 GPU 着色代码的 64 组角度和粗糙度组合，允许误差为 `1e-4 × max(1, abs(reference))`。本机最大绝对误差约 `4.681e-5`。同脚本检查材质与工程往返保存、低粗糙度、贴图上传、损坏输入和试衣帧保持。`verify-material-renders.cjs` 重做四组材质输出。`verify-optics.cjs` 检查新节点图的编辑、循环拒绝、独立背光散射和样衣 GLB，并生成实际棚拍。两者使用 Khronos glTF Validator，可通过 `GLTF_VALIDATOR` 指定模块位置。可传入输出目录，默认写入系统临时目录。

## 适用范围

本版适用于样衣轮廓设计、配缝、裙装叠层试穿和面料展示。使用简化躯干人台，尚未实现手臂与腿部碰撞、通用布料自碰撞、任意造型的多层接触、生产级面料标定、放码和 CLO ZPRJ 兼容。统一缝份未区分折边工艺。全局照明使用实时渲染近似。与 CLO 的对照基于其公开操作文档，尚未使用同纸样、同人台在原软件中做数值对标。[CLO 缝纫操作](https://support.clo3d.com/hc/en-us/articles/115000498767--2D-Tool-Segment-Sewing)

运行时库和许可证在 `vendor/` 中，含 Three.js r160、同版本的 GLTFExporter、Poly2Tri 和 Clipper。
